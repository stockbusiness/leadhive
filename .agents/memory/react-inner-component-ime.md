---

## ルール
コンポーネント関数の**内部**にサブコンポーネント（`const Foo = () => ...` や `function Foo() {...}`）を定義してはいけない。必ずモジュールのトップレベルに定義すること。

**Why:** Reactはコンポーネントの「型（関数参照）」が変わると別コンポーネントとして扱いアンマウント→マウントする。内部定義だとレンダリングのたびに新しい関数参照が生成されるため、状態変化（=キー入力）のたびに子コンポーネントが再マウントされ、IMEのコンポジション状態・フォーカス・入力途中のテキストがすべてリセットされる。

**How to apply:**
- フォーム、モーダル、リストアイテムなど、stateを持つ親の中で使うサブコンポーネントはすべてトップレベルに移動する
- props経由で必要なデータ・コールバックを渡せばよい
- 発生場所: `frontend/src/pages/FormProfiles.tsx` の `ProfileForm` を内部定義していたことで発覚（2026-06-01）
