# Webhook API リファレンス

外部システムから Hubsrev に問い合わせを送信するための API です。  
フォーム送信・メール転送・チャットボットなどとの連携に使用します。

---

## 認証

API Key をリクエストヘッダーに付与してください。  
API Key は管理画面の「API Key管理」から発行できます。

```http
Authorization: Bearer hubsrev_xxxxxxxxxxxxxxxxxxxxxxxx
```

API Key はプロダクトに紐づいており、送信された問い合わせは自動的に  
そのプロダクトの受信ボックスに届きます。

---

## エンドポイント

### 問い合わせ受信

```
POST /api/webhook/inbox
```

外部システムからの問い合わせを Hubsrev の統合受信ボックスに送信します。

#### リクエストボディ

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| `senderName` | string | ✅ | 送信者名（例：「山田 太郎」） |
| `senderEmail` | string | ✅ | 送信者メールアドレス |
| `subject` | string | ✅ | 件名 |
| `bodyText` | string | ✅ | 本文（プレーンテキスト） |
| `senderCompany` | string | — | 送信者の会社名 |
| `bodyHtml` | string | — | 本文（HTML形式） |
| `sourceSystem` | string | — | 送信元システム名（例：「公式サイト」「ECサイト」） |
| `sourceType` | string | — | 送信元種別（`form` / `email` / `ticket_reply`、デフォルト: `form`） |

#### リクエスト例

```json
{
  "senderName": "山田 太郎",
  "senderEmail": "taro.yamada@example.com",
  "senderCompany": "株式会社サンプル",
  "subject": "注文した商品がまだ届きません",
  "bodyText": "先週注文した商品（注文番号: ORD-12345）がまだ届いていません。\n確認をお願いします。",
  "bodyHtml": "<p>先週注文した商品（注文番号: ORD-12345）がまだ届いていません。</p>",
  "sourceSystem": "ECサイト",
  "sourceType": "form"
}
```

#### レスポンス

**成功 (201 Created)**

```json
{
  "id": 42,
  "inboxNo": "INB-0042"
}
```

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `id` | number | 受信ボックスアイテムの内部ID |
| `inboxNo` | string | 受信番号（「INB-XXXX」形式） |

---

## sourceType の選択基準

| 値 | 用途 |
|----|------|
| `form` | Webフォームからの送信（デフォルト） |
| `email` | メールからの転送・取り込み |
| `ticket_reply` | 顧客からのチケット返信 |

---

## 利用制限（レートリミット）

プランごとに1ヶ月あたりの受信上限があります。

| プラン | 受信上限 |
|--------|----------|
| Starter | 500件/月 |
| Growth | 2,000件/月 |
| Scale | 10,000件/月 |
| Enterprise | 無制限 |

上限に達した場合、以下のレスポンスが返ります：

```json
{
  "error": "受信ボックスの上限に達しました。プランをアップグレードしてください。"
}
```

---

## エラーレスポンス

| HTTPステータス | エラー内容 | 対処方法 |
|--------------|-----------|---------|
| `400 Bad Request` | リクエストボディの形式不正 | 必須フィールドを確認してください |
| `401 Unauthorized` | API Key が未指定または無効 | ヘッダーの API Key を確認してください |
| `403 Forbidden` | 受信上限超過 | プランをアップグレードしてください |
| `500 Internal Server Error` | サーバーエラー | 時間をおいて再試行してください |

## 実装サンプル

### Node.js

```javascript
const axios = require('axios');

async function sendInquiry(inquiry) {
  const response = await axios.post(
    'https://<your-domain>/api/webhook/inbox',
    {
      senderName: inquiry.name,
      senderEmail: inquiry.email,
      senderCompany: inquiry.company,
      subject: inquiry.subject,
      bodyText: inquiry.message,
      sourceSystem: '公式サイト',
      sourceType: 'form',
    },
    {
      headers: {
        'Authorization': `Bearer ${process.env.HUBSREV_API_KEY}`,
        'Content-Type': 'application/json',
      },
    }
  );
  return response.data; // { id: 42, inboxNo: "INB-0042" }
}
```

### PHP

```php
<?php
function sendInquiry(array $inquiry): array {
    $ch = curl_init('https://<your-domain>/api/webhook/inbox');
    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_POST => true,
        CURLOPT_POSTFIELDS => json_encode([
            'senderName'    => $inquiry['name'],
            'senderEmail'   => $inquiry['email'],
            'senderCompany' => $inquiry['company'] ?? null,
            'subject'       => $inquiry['subject'],
            'bodyText'      => $inquiry['message'],
            'sourceSystem'  => '公式サイト',
            'sourceType'    => 'form',
        ]),
        CURLOPT_HTTPHEADER => [
            'Authorization: Bearer ' . getenv('HUBSREV_API_KEY'),
            'Content-Type: application/json',
        ],
    ]);
    $response = curl_exec($ch);
    curl_close($ch);
    return json_decode($response, true);
}
```

### WordPress / Contact Form 7 との連携例

```php
// functions.php に追加
add_action('wpcf7_mail_sent', function($contact_form) {
    $submission = WPCF7_Submission::get_instance();
    $data = $submission->get_posted_data();

    wp_remote_post('https://<your-domain>/api/webhook/inbox', [
        'headers' => [
            'Authorization' => 'Bearer ' . get_option('hubsrev_api_key'),
            'Content-Type'  => 'application/json',
        ],
        'body' => json_encode([
            'senderName'  => $data['your-name'],
            'senderEmail' => $data['your-email'],
            'subject'     => $data['your-subject'],
            'bodyText'    => $data['your-message'],
            'sourceSystem'=> 'WordPressサイト',
            'sourceType'  => 'form',
        ]),
    ]);
});
```

## セキュリティ推奨事項

1. **API Key を環境変数に保管する** — ソースコードや Git リポジトリにハードコードしないこと
2. **HTTPS 必須** — 本番環境では必ず HTTPS を使用すること
3. **送信元IPアドレスの制限** — 可能であればサーバー側で送信元IPを制限すること
4. **API Key のローテーション** — 定期的に API Key を再発行することを推奨
