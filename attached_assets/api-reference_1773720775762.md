# REST API リファレンス

すべての内部 API エンドポイントの一覧です。  
内部 API（`/api/auth/login` 以外）はセッション Cookie 認証を使用します。

> **外部連携用** は [webhook.md](./webhook.md) を参照してください。

---

## 認証 (Auth)

### ログイン

```
POST /api/auth/login
```

**リクエスト**
```json
{ "username": "admin", "password": "admin123" }
```

**レスポンス (200)**
```json
{
  "id": 1,
  "username": "admin",
  "displayName": "管理者",
  "role": "admin",
  "tenantId": 1
}
```

---

### ログアウト

```
POST /api/auth/logout
```

---

### パスワードリセット申請

```
POST /api/auth/forgot-password
```

```json
{ "email": "user@example.com" }
```

---

### パスワードリセット実行

```
POST /api/auth/reset-password
```

```json
{ "token": "リセットトークン", "password": "新しいパスワード" }
```

---

### パスワード変更（ログイン中）

```
PATCH /api/auth/password
```

```json
{ "currentPassword": "旧パスワード", "newPassword": "新パスワード" }
```

---

### メール確認

```

```

## チケット管理 (Support Hub)

### チケット一覧

```
GET /api/support-hub/tickets
```

**クエリパラメータ**

| パラメータ | 型 | 説明 |
|-----------|-----|------|
| `status` | string | ステータスで絞り込み（`new` / `open` / `pending` / `waiting_customer` / `resolved` / `closed`） |
| `priority` | string | 優先度で絞り込み（`low` / `medium` / `high` / `urgent`） |
| `productId` | number | プロダクトIDで絞り込み |
| `assignedUserId` | number | 担当者IDで絞り込み |
| `search` | string | 件名・顧客名の全文検索 |

**レスポンス (200)**
```json
[
  {
    "id": 1,
    "hubTicketNo": "HUB-0001",
    "status": "open",
    "priority": "high",
    "subject": "ログインできません",
    "customerName": "山田 太郎",
    "customerEmail": "taro@example.com",
    "customerCompany": "株式会社サンプル",
    "productId": 1,
    "assignedUserId": 2,
    "slaDueAt": "2026-03-15T12:00:00.000Z",
    "createdAt": "2026-03-11T09:00:00.000Z",
    "updatedAt": "2026-03-11T10:30:00.000Z"
  }
]
```

## LP問い合わせ管理（マルチテナント対応）

### 問い合わせ一覧・操作

**権限:** `admin` または `member`（自テナントのデータのみ返却）

```
GET    /api/lp/inquiries                  # 問い合わせ一覧（type/statusフィルタ可）
PATCH  /api/lp/inquiries/:id/status       # ステータス変更
POST   /api/lp/inquiries/:id/reply        # 返信メール送信
```

#### `GET /api/lp/inquiries`

クエリパラメータ:
- `type` — `document_request` / `partner_apply` / `founder_apply` / `contact` / `email_inbound` / `webhook_inbound`
- `status` — `new` / `contacted` / `in_progress` / `closed`

レスポンス例:
```json
[
  {
    "id": 1,
    "tenantId": 2,
    "type": "email_inbound",
    "companyName": "株式会社サンプル",
    "contactName": "山田 太郎",
    "email": "yamada@example.com",
    "phone": null,
    "message": "【件名】お問い合わせ\n\n本文...",
    "status": "new",
    "repliedAt": null,
    "replyCount": 0,
    "createdAt": "2026-03-17T00:00:00.000Z"
  }
]
```

#### `PATCH /api/lp/inquiries/:id/status`

```json
{ "status": "contacted" }
```

ステータス値: `new` → `contacted` → `in_progress` → `closed`

#### `POST /api/lp/inquiries/:id/reply`

リクエスト:
```json
{
  "subject": "Re: お問い合わせありがとうございます",
  "body": "山田様\n\nお問い合わせありがとうございます。\n\n..."
}
```

送信後の自動処理:
- 設定済みSMTP（テナントのメール送信設定）経由でメール送信
- `replied_at` = 現在日時に更新
- `reply_count` をインクリメント
- `status` を `contacted` に変更

### IMAP受信設定（管理者）

**権限:** `admin`（テナントスコープ）

```
GET  /api/admin/imap-settings        # IMAP設定取得（password は "••••••••" でマスク）
PUT  /api/admin/imap-settings        # IMAP設定保存
POST /api/admin/imap-settings/test   # 接続テスト
```

#### `PUT /api/admin/imap-settings` リクエスト

```json
{
  "enabled": true,
  "host": "imap.gmail.com",
  "port": 993,
  "secure": true,
  "username": "your@gmail.com",
  "password": "xxxx xxxx xxxx xxxx",
  "folder": "INBOX",
  "pollIntervalMinutes": 5
}
```

> **Gmail利用時の注意**: 通常パスワード不可。Googleアカウント → セキュリティ → 2段階認証 ON → アプリパスワードを生成して使用。

プリセット:
| サービス | host | port | secure |
|---|---|---|---|
| Gmail | imap.gmail.com | 993 | true |
| さくらインターネット | mail.〈ドメイン〉 | 993 | true |
| Xserver | 〈サーバーID〉.xserver.jp | 993 | true |
| Outlook/Office 365 | outlook.office365.com | 993 | true |

**ポーリング動作**: `startImapPolling()` がサーバー起動時に呼ばれ、5分ごとに全テナントの有効なIMAP設定を並列チェック。未読メールを `email_inbound` として `lp_inquiries` に登録後、既読マークを付与。

### Webhook受信設定（管理者）

**権限:** `admin`（テナントスコープ）

```
GET    /api/admin/inbound-webhooks        # Webhookソース一覧
POST   /api/admin/inbound-webhooks        # Webhookソース作成
PUT    /api/admin/inbound-webhooks/:id    # 更新
DELETE /api/admin/inbound-webhooks/:id    # 削除
```

#### `POST /api/admin/inbound-webhooks` リクエスト

```json
{
  "name": "Shopify注文フォーム",
  "enabled": true,
  "nameField": "customer_name",
  "emailField": "customer_email",
  "companyField": "company",
  "phoneField": "phone",
  "messageField": "order_note"
}
```

作成後に `sourceKey`（48文字のhex）が自動生成され、受信URLが払い出される。

#### Webhook受信エンドポイント（認証不要）

```
POST /api/public/webhook/:sourceKey
```

- `sourceKey` からWebhookレコードを特定し、紐づく `tenantId` を継承して `lp_inquiries` に登録
- フィールドマッピング設定に従って `company_name` / `contact_name` / `email` / `phone` / `message` を抽出
- 未マッピングフィールドは全キーをまとめてメッセージ本文に格納
- `total_received` カウンタと `last_received_at` を更新

対応プリセット: Shopify / Formrun / Tayori / Google Forms / 汎用
