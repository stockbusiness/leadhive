## 追加推奨：パイプライン ステータス一覧の挿入

資料内でパイプラインを説明する際に、以下の表を挿入することを推奨します。

| # | ステータス | 意味 |
|---|-----------|------|
| 1 | 未確認 | 収集直後。まだ担当者が確認していない企業 |
| 2 | 対象候補 | 確認してアプローチ対象と判断した企業 |
| 3 | 除外 | 営業対象外と判断（スクリーニングで除外） |
| 4 | アプローチ前 | 対象確定したが未着手 |
| 5 | フォーム送信済 | 問い合わせフォームからコンタクト済み |
| 6 | 返信あり | 先方から返信が来た |
| 7 | 面談化 | 面談の約束が取れた（重要マイルストーン） |
| 8 | 代理店化 | 成約・代理店契約締結（完了） |
| 9 | 失注 | 商談不成立（完了） |
