# LeadHive 収集データ仕様

> 対象システム：LeadHive（株式会社LEADMARK 販売 / Lumiq Brain合同会社 開発）  
> ドメイン：leadhive.work

---

## 1. データ収集の流れ

```
① キーワード検索収集（Serper / Google / DuckDuckGo）
        ↓
② 企業Webサイトのスクレイピング
        ↓
③ gBizINFO APIで公式情報を補完（法人番号・住所など）
        ↓
④ 分類・スコアリング
        ↓
⑤ 候補企業一覧（プロジェクト内）または候補企業マスターに保存
```

---

## 3. データソースと制限事項

### gBizINFO API
- **対象**：法人番号が登録されている日本企業
- **取得内容**：正式社名・所在地・法人番号・サイトURL（登録されている場合）
- **制限**：法人番号がない企業はAPI検索不可

### Webスクレイピング
- **対象**：`robots.txt` で禁止されていないサイト
- **除外対象**：ポータルサイト・まとめサイト・求人サイト・SNS等のアグリゲーターサイト
- **タイムアウト**：1社あたり最大10秒

### 検索エンジン
優先順位：①gBizINFO → ②Serper API → ③Google Custom Search → ④DuckDuckGo → ⑤Google直接 → ⑥ドメイン推測

## 4. 自動収集バッチの仕様

| 処理 | スケジュール | 1回あたり処理数 | 最大実行時間 |
|---|---|---|---|
| キーワード収集 | 管理者設定時刻 | 設定による | — |
| gBizINFO一括収集 | 管理者設定時刻（深夜） | 設定による | — |
| URLなし企業補完（AutoMasterEnrich） | JST 1時・5時・9時（4時間ごと） | 最大30社/回 | 15分で強制終了 |
| 全企業エンリッチ | JST 4時（1日1回） | 全件 | — |

## 5. データの保存先

| 保存先 | 用途 |
|---|---|
| **候補企業マスター（CompanyMaster）** | 全組織共通の企業データベース。収集した企業情報を一元管理 |
| **候補企業一覧（Company）** | プロジェクトごとの企業リスト。ステータス管理・営業活動に使用 |
