## 1. はじめに・基本的な使い方の流れ

このツールは、EC・Shopify支援会社などの代理店候補を**効率的に発掘・評価・営業管理**するためのシステムです。

### 基本的な運用フロー

```
① プロジェクト作成（目的別に分けて管理）
        ↓
② APIキー設定（Google検索を使う場合）
        ↓
③ 検索キーワード登録
        ↓
④ 企業を自動収集（複数の収集方法から選択）
        ↓
⑤ 収集した企業を確認・スコアで絞り込み
        ↓
⑥ ステータスを更新しながら営業活動を記録
        ↓
⑦ 定期的に自動収集を回してリストを拡充
```

## 2. 初期セットアップ

### 2-1. Google Custom Search APIの設定（推奨）

自動収集機能を最大限活用するためにGoogle APIキーを設定します。

1. サイドバー下部の **「設定」** を開く
2. 「Google Custom Search API 設定」セクションで以下を入力：
   - **Google API Key**: Google Cloud Consoleで取得したAPIキー
   - **Search Engine ID (cx)**: Programmable Search Engineで作成したID
3. **「保存」** をクリック
4. **「接続テスト」** で動作確認

> Google Custom Search APIは1日100回まで無料で使用できます。ダッシュボードのAPI使用量カードで残り回数を確認できます。

### 2-2. Google Places APIの設定（Googleマップ収集を使う場合）

1. 設定画面の「Google Places API Key」に入力・保存
2. これでGoogleマップタブが利用可能になります

### 2-3. Slack通知の設定（任意）

収集完了時にSlackに通知を受け取れます。

1. 設定画面の「Slack通知設定」セクションでWebhook URLを入力
2. **「保存」** → **「テスト送信」** で疎通確認

## 3. プロジェクト管理

### プロジェクトとは

「Shopify代理店候補」「EC運営代行候補」「関西エリア限定」などのように、**目的や条件ごとにデータを分けて管理**するための単位です。

### プロジェクトの作成

1. サイドバーの **「プロジェクト管理」** を開く
2. **「新規プロジェクト」** ボタンをクリック
3. プロジェクト名・説明・業種を入力
4. 必要に応じてカテゴリ・スコアリングをカスタマイズ
5. **「作成」** をクリック

### プロジェクトの切り替え

サイドバー上部のドロップダウンから切り替えます。切り替えると、全画面のデータが選択したプロジェクトのものに絞り込まれます。

### プロジェクトのカスタマイズ（上級）

プロジェクト編集画面から以下をカスタマイズできます：

- **カテゴリ定義**: どのキーワードがヒットしたらどのカテゴリに分類するかを設定
- **フラグ定義**: Shopify判定・EC判定などのキーワードをカスタマイズ
- **スコアリングルール**: 各フラグの点数をプロジェクトの目的に合わせて調整

## 4. 企業の収集

### 4-1. Google API検索（最も精度が高い方法）

1. サイドバーの **「URL収集」** を開く
2. 「Google API検索」タブを選択
3. 「対象キーワード」で収集したいキーワードを選択（「全キーワード一括収集」も可）
4. **「収集開始」** をクリック
5. 画面にプログレスバーが表示され、進捗をリアルタイムで確認できます

> キーワードが未登録の場合は「検索条件管理」画面で先にキーワードを追加してください。

### 4-2. 検索キーワードの登録

1. サイドバーの **「検索条件管理」** を開く
2. **「キーワードを追加」** ボタンをクリック
3. 以下を入力：
   - **キーワード**: 例 `Shopify 制作会社`
   - **カテゴリ**: 収集結果のカテゴリ分類に使用
   - **地域**: 例 `東京` （キーワードに地域を付加）
   - **除外キーワード**: 例 `比較, ランキング` （まとめサイトを除外）
4. **「追加」** をクリック

### 4-3. ディレクトリ収集（企業一覧ページから収集）

業界団体の会員一覧や、比較サイトの掲載企業リストなどから収集できます。

1. 「URL収集」→「ディレクトリ収集」タブ
2. 企業一覧ページのURLを入力（例: `https://example.com/members`）
3. 最大ページ数を設定
4. **「収集開始」** をクリック

### 4-4. Google直接検索（APIキー不要）

1. 「URL収集」→「Google直接検索」タブ
2. 検索キーワード・地域・取得件数を入力
3. **「検索収集」** をクリック

> Google利用規約に注意。過度な頻度での利用はIPブロックの原因になります。

### 4-5. Shopifyパートナー収集

1. 「URL収集」→「Shopifyパートナー」タブ
2. 最大取得件数を選択
3. **「Shopifyパートナー収集」** をクリック

### 4-6. Googleマップ収集

地域に根ざした企業や、住所・電話番号情報が必要な場合に有効です。

1. 「URL収集」→「Googleマップ」タブ
2. 検索キーワード・地域・件数を入力
3. **「マップ検索」** をクリック

> Google Places API Keyの設定が必要です（設定画面で登録）。

### 4-7. URLを直接入力して取得

特定の企業サイトを手動で追加したい場合：

1. 「URL収集」画面の下部「単一URL取得」セクション
2. 企業サイトのURLを入力
3. **「取得」** をクリック → 自動で会社情報を抽出・登録

複数のURLをまとめて登録する場合は「一括URL取得」に1行1URLで入力します。

### 4-8. 自動収集スケジュール

毎日決まった時刻に自動収集を実行できます。

1. 設定画面の「自動収集スケジュール」セクション
2. 「自動収集を有効にする」をON
3. 実行時刻を設定
4. **「保存」** をクリック

## 5. 候補企業の管理・評価

### 5-1. 候補企業一覧の見方

サイドバーの **「候補企業一覧」** を開きます。

| 列 | 説明 |
|---|------|
| 会社名 | 会社名とドメイン。Shopify/Amazon/楽天フラグバッジも表示 |
| カテゴリ | 自動分類されたカテゴリ |
| スコア | 0〜100点のスコアとランク（A/B/C/D） |
| 所在地 | 都道府県・市区町村・電話番号 |
| 問い合わせ | 問い合わせページへのリンク |
| ステータス | 現在の営業ステータス |
| メモ | 最新メモ（抜粋） |

### 5-2. 絞り込み

画面上部のフィルターバーで以下の条件で絞り込めます：

- **カテゴリ**: EC制作、Shopify支援など
- **ステータス**: 未確認、アプローチ前、面談化など
- **スコアランク**: A/B/C/D
- **問い合わせ**: 問い合わせページあり/なしで絞り込み
- **フリーワード検索**: 会社名・ドメインで検索
- **タグ**: 付与されたタグで絞り込み

### 5-3. ステータスの管理

営業フローに沿ったステータスで進捗を管理します：

| ステータス | 意味 |
|-----------|------|
| 未確認 | 収集直後。まだ内容を確認していない |
| 対象候補 | 確認してアプローチ対象と判断 |
| 除外 | アプローチ不要と判断（業種不一致等） |
| アプローチ前 | アプローチ準備完了 |
| フォーム送信済 | 問い合わせフォームからコンタクト済み |
| 返信あり | 先方から返信が来た |
| 面談化 | 面談の約束が取れた |
| 代理店化 | 代理店契約完了 |
| 失注 | 断られた・見込みなし |

ステータスは一覧画面のドロップダウンから直接変更できます。

### 5-4. 企業の詳細編集

企業行の「鉛筆アイコン」をクリックして詳細編集モーダルを開きます。

編集できる内容：
- 基本情報（会社名、URL、電話、メール、所在地）
- カテゴリ・フラグ（Shopify/EC/Amazon/楽天等）
- スコア手動調整（-30〜+30点）
- メモ・内部ノート
- タグの付与・削除
- ステータス変更履歴の閲覧
- 営業活動ログの記録

### 5-5. 一括操作

複数企業を選択（チェックボックス）すると、バルクアクションバーが表示されます：

**一括ステータス変更**:
1. 変更したい企業にチェックを入れる
2. バルクアクションバーのドロップダウンでステータスを選択
3. **「一括変更」** をクリック

**プロジェクト間移動**:
1. 移動したい企業にチェックを入れる
2. **「プロジェクト移動」** ボタンをクリック
3. 移動先プロジェクトを選択
4. **「移動実行」** をクリック

> 移動先に同じドメインの企業が既に存在する場合は自動的にスキップされます。

### 5-6. 再スクレイピング

企業情報が古くなった場合、最新の情報に更新できます。

1. 対象企業の行の「回転矢印アイコン」をクリック
2. 自動でWebサイトを再スクレイピング
3. カテゴリ・フラグ・スコアが更新される（手動調整スコアは保持）

## 6. マスターDB — 横断検索とインポート

マスターDBは、**全プロジェクト共通の企業プール**です。どのプロジェクトで収集した企業でも、収集時に自動的にマスターDBにも登録されます。

### マスターDBの使い方

1. サイドバーの **「マスターDB」** を開く

**統計カードの確認**:
ページ上部に「総登録件数」と収集元別の件数が表示されます。

**企業の検索**:
1. 検索バーにキーワードを入力（会社名・ドメイン・カテゴリ・都道府県）
2. カテゴリ・都道府県・最低スコアで絞り込みも可能
3. **「検索」** をクリック（またはEnterキー）

**プロジェクトへのインポート**:
1. サイドバーで対象プロジェクトに切り替えておく
2. マスターDBで企業を検索
3. 「登録済み」バッジがない企業にチェックを入れる
4. 右上の **「現在のプロジェクトにインポート」** ボタンをクリック
5. 完了メッセージで成功/重複/エラー件数を確認

> 「登録済み」バッジが付いている企業は現在のプロジェクトに既に存在するため、チェックボックスが無効になります。

### 活用シーン

- **別プロジェクトの成果を再利用**: 「東京特化プロジェクト」で収集した企業を「全国プロジェクト」でも使いたい場合に便利
- **過去に収集した企業の発掘**: 古いプロジェクトで収集した企業を新しいプロジェクトで活用
- **大量インポート**: 一度に多くの企業を素早く登録したい場合

## 7. ダッシュボードの見方

サイドバーの **「ダッシュボード」** を開きます。

### 統計カード（上部）

| カード | 説明 |
|-------|------|
| 総収集件数 | プロジェクト内の全企業数 |
| 重複除外後 | ユニークドメイン数 |
| 未確認 | まだステータスが「未確認」の企業数 |
| 高スコア (A/B) | ランクA・Bの企業数 |
| 問い合わせあり | 問い合わせURLを持つ企業数 |
| API使用量 | 本日のGoogle API使用回数（上限100回/日） |

### グラフ

| グラフ | 説明 |
|-------|------|
| カテゴリ別内訳 | 企業のカテゴリ分布（円グラフ） |
| スコアランク分布 | A〜Dランクの件数（棒グラフ） |
| ステータス別 | 各ステータスの件数（横棒グラフ） |
| 都道府県別（上位10） | 所在地の分布（横棒グラフ） |
| 直近30日の収集件数推移 | 日別の収集実績（折れ線グラフ） |

> グラフは現在選択中のプロジェクトのデータのみを表示します。

## 8. 営業活動の記録

### 活動ログの記録

企業の詳細編集モーダルの「活動ログ」タブから記録できます。

アクション種別：
- **電話**: 電話でのコンタクト
- **メール**: メール送信
- **フォーム送信**: 問い合わせフォームから送信
- **面談**: 面談実施
- **その他**: 上記以外

### メモテンプレートの活用

よく使うメモ文面をテンプレートとして登録しておくと、入力の手間を省けます。

1. サイドバーの **「メモテンプレート」** を開く
2. **「テンプレートを追加」** でテンプレートを作成
3. 企業詳細モーダルのメモ欄から「テンプレートを挿入」で呼び出す

### メールテンプレートの活用

1. 「メモテンプレート」→「メールテンプレート」タブでメールの雛形を作成
2. `{{company_name}}` などの変数を使って、企業名を自動挿入
3. 企業詳細モーダルの「メールテンプレート」タブから、変数が展開された状態でコピーまたはmailto:リンクを開ける

## 9. CSV出力・データ活用

### CSVエクスポート

1. 「候補企業一覧」を開く
2. 絞り込みフィルターを設定（出力したい条件で絞り込む）
3. 右上の **「CSV出力」** ボタンをクリック
4. 現在のフィルター状態が反映されたCSVがダウンロードされる

### 主な出力項目

会社名、ドメイン、WebサイトURL、問い合わせURL、電話番号、メールアドレス、都道府県、市区町村、カテゴリ、スコア、ランク、ステータス、各フラグ、メモ、作成日時

## 10. 便利な管理機能

### 10-1. 重複検出・マージ

同じ企業が複数登録されてしまった場合に統合できます。

1. 「候補企業一覧」右上の **「重複チェック」** をクリック
2. 重複グループが表示される
3. 各グループで「メイン企業」（残す方）をラジオボタンで選択
4. **「マージ実行」** → 他の企業の情報がメインに統合され削除される

### 10-2. 拒否リストの管理

収集から除外したいドメインを管理します。

1. サイドバーの **「拒否リスト」** を開く
2. まとめサイト・競合・無関係なサイトは自動で登録されます
3. **「追加」** ボタンで手動でも登録可能（例: 自社サイト、パートナー企業等）

拒否リストに登録されたドメインは、以降の収集で自動的にスキップされます。

### 10-3. 収集履歴の確認

1. サイドバーの **「収集履歴」** を開く
2. 過去の収集実行の結果一覧（いつ、どのキーワードで、何件収集/除外/重複したか）を確認できる

## 11. 設定・通知

### Google Custom Search API

| 設定項目 | 説明 |
|---------|------|
| Google API Key | Google Cloud ConsoleのAPIキー |
| Search Engine ID (cx) | Programmable Search Engineで作成したID |

取得方法:
1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクト作成
2. Custom Search APIを有効化
3. 認証情報 → APIキーを作成
4. [Programmable Search Engine](https://programmablesearchengine.google.com/) でSearch Engineを作成してIDを取得

### Google Places API（Googleマップ収集用）

1. Google Cloud ConsoleでPlaces APIを有効化
2. 同じAPIキーを使用（または別途作成）

### Slack通知

| 設定項目 | 説明 |
|---------|------|
| Slack Webhook URL | Slack App の Incoming Webhook URL |

取得方法:
1. [Slack API](https://api.slack.com/apps) でAppを作成
2. 「Incoming Webhooks」を有効化
3. 通知を送りたいチャンネルにWebhook URLを追加

### 自動収集スケジュール

| 設定項目 | 説明 |
|---------|------|
| 自動収集を有効にする | ON/OFFトグル |
| 実行時刻 | 毎日のバッチ実行時刻（サーバー時刻基準） |

自動収集は、アクティブなキーワード（「検索条件管理」でアクティブにしたもの）を全て実行します。

## 12. よくある質問

### Q. 収集しても企業が0件のまま

A. 以下を確認してください：
- 設定画面でGoogle API KeyとSearch Engine ID (cx) が正しく保存されているか
- 「接続テスト」ボタンで接続が成功するか
- API使用量が上限（100回/日）に達していないか（ダッシュボードで確認）

### Q. 同じ企業が何度も収集される

A. 同一プロジェクト内では同一ドメインの重複収集は自動的にスキップされます。もし重複している場合は「重複チェック」機能でマージしてください。

### Q. スコアが低い企業をフィルタで隠したい

A. 「候補企業一覧」のフィルターバーで「スコアランク」をA・Bに設定すると、高スコアの企業だけ表示できます。

### Q. 収集した企業を別のプロジェクトでも使いたい

A. 2つの方法があります：
1. **プロジェクト間移動**: 企業一覧でチェックして「プロジェクト移動」
2. **マスターDBからインポート**: マスターDB画面で検索して「インポート」

### Q. Googleマップ収集で「APIキーが設定されていません」と表示される

A. 設定画面の「Google Places API Key」フィールドに入力・保存してください（Google Custom Search APIとは別のキーです）。

### Q. 自動収集が実行されない

A. 以下を確認してください：
- 設定画面で「自動収集を有効にする」がONになっているか
- 「検索条件管理」でアクティブなキーワードが1件以上あるか
- サーバーが起動中かどうか（自動収集はサーバーが動いている間のみ実行）
- 設定画面のスケジューラ状態が「稼働中」になっているか

### Q. Slack通知が届かない

A. 以下を確認してください：
- 設定画面でWebhook URLが正しく保存されているか（「テスト送信」で確認）
- 収集で成功件数が1件以上あるか（0件の場合は通知されません）

### Q. CSVに出力されるデータが少ない

A. 現在のフィルター条件のみが出力されます。全件出力する場合はフィルターをリセット（全条件を「すべて」）した状態でCSV出力してください。

### Q. 企業情報が不完全（会社名や電話番号がない）

A. Webサイトの構造によっては自動抽出できない場合があります。企業の詳細編集モーダルから手動で補完してください。情報を手動入力した後は「スコア再計算」が自動的に行われます。
