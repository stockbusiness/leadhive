## 1. はじめに・基本的な使い方の流れ

LeadHiveは、EC・Shopify支援会社などの代理店候補を**効率的に発掘・評価・営業管理**するためのBtoB営業支援ツールです。

### 基本的な運用フロー

```
① アカウント登録・プロジェクト作成
        ↓
② APIキー設定（Google検索・OpenAI等）
        ↓
③ 検索キーワード登録
        ↓
④ 企業を自動収集（複数の収集方法から選択）
        ↓
⑤ 収集した企業を確認・スコアで絞り込み
        ↓
⑥ AI分析でリサーチを自動化
        ↓
⑦ AIメールで営業文面を作成
        ↓
⑧ ステータスを更新しながら営業活動を記録
        ↓
⑨ 定期的に自動収集を回してリストを拡充
```

## 2. アカウント登録・ログイン

### 新規登録

1. トップページの **「無料で始める」** または **「アカウント登録」** をクリック
2. メールアドレス・表示名・パスワードを入力
3. **「登録する」** をクリック → 組織が自動作成され、ダッシュボードへ遷移

### ログイン

1. **/login** ページでメールアドレス・パスワードを入力
2. **「ログイン」** をクリック

### パスワードを忘れた場合

1. ログイン画面の **「パスワードをお忘れですか？」** をクリック
2. 登録済みメールアドレスを入力して送信
3. 届いたメール内のリセットリンクをクリックして新しいパスワードを設定

### メンバーとして招待された場合

1. 招待メール内のリンクをクリック
2. 表示名とパスワードを設定して参加

## 3. 初期セットアップ

### 3-0. オンボーディングウィザード（初回ログイン時）

アカウント登録後、初回ログイン時に**6ステップのセットアップウィザード**が自動表示されます。

| ステップ | 内容 |
|---------|------|
| 1. ようこそ | LeadHiveの概要と基本フローの紹介 |
| 2. 組織名の設定 | 自社名や組織名を入力 |
| 3. プロジェクト作成 | 最初のプロジェクト名を入力 |
| 4. キーワード登録 | 最初の検索キーワードを1件登録 |
| 5. Google APIキー設定 | Google Custom Search APIキーとSearch Engine IDを入力 |
| 6. 完了 | 設定完了 → ダッシュボードへ遷移 |

> ウィザードをスキップしても、後から設定画面でいつでも変更できます。

### 3-1. Google Custom Search APIの設定（推奨）

1. サイドバー下部の **「設定」** を開く
2. 「Google Custom Search API 設定」セクションで以下を入力：
   - **Google API Key**: Google Cloud Consoleで取得したAPIキー
   - **Search Engine ID (cx)**: Programmable Search Engineで作成したID
3. **「保存」** → **「接続テスト」** で動作確認

> Google Custom Search APIは1日100回まで無料。ダッシュボードのAPI使用量カードで残り回数を確認できます。

### 3-2. Google Places APIの設定（Googleマップ収集を使う場合）

1. 設定画面の「Google Places API Key」に入力・保存
2. これでURL収集画面の「Googleマップ」タブが利用可能になります

### 3-3. OpenAI APIの設定（AI機能を使う場合）

1. 設定画面の「OpenAI API設定」セクションでAPIキーを入力・保存
2. これでAI企業分析とアウトリーチメール生成が利用可能になります

> APIキーは [OpenAI Platform](https://platform.openai.com/api-keys) から取得できます。

### 3-4. Slack通知の設定（任意）

1. 設定画面の「Slack通知設定」でWebhook URLを入力
2. **「保存」** → **「テスト送信」** で疎通確認

### 3-5. メール通知の設定（任意）

1. 設定画面の「メール通知設定（SMTP）」セクションで以下を入力：
   - SMTPサーバーホスト・ポート
   - ユーザー名・パスワード
   - 送信元メールアドレス
2. **「保存」** をクリック

## 4. プロジェクト管理

### プロジェクトとは

「Shopify代理店候補」「EC運営代行候補」「関西エリア限定」などのように、**目的や条件ごとにデータを分けて管理**するための単位です。

### プロジェクトの作成

1. サイドバーの **「プロジェクト管理」** を開く
2. **「新規プロジェクト」** ボタンをクリック
3. プロジェクト名・説明・業種を入力して **「作成」**

### プロジェクトの切り替え

サイドバー上部のドロップダウンから切り替えます。切り替えると全画面のデータが選択したプロジェクトのものに絞り込まれます。

### プロジェクトのカスタマイズ（上級）

プロジェクト編集画面から以下をカスタマイズできます：

- **カテゴリ定義**: どのキーワードがヒットしたらどのカテゴリに分類するかを設定
- **フラグ定義**: Shopify判定・EC判定などのキーワードをカスタマイズ
- **スコアリングルール**: 各フラグの点数をプロジェクトの目的に合わせて調整

## 5. 企業の収集

### 5-1. Google API検索（最も精度が高い方法）

1. サイドバーの **「URL収集」** を開く
2. 「Google API検索」タブを選択
3. 対象キーワードを選択（「全キーワード一括収集」も可）
4. **「収集開始」** → プログレスバーでリアルタイム進捗を確認

> キーワードが未登録の場合は「検索条件管理」画面で先にキーワードを追加してください。

### 5-2. 検索キーワードの登録

1. サイドバーの **「検索条件管理」** を開く
2. **「キーワードを追加」** ボタンをクリック
3. 以下を入力して保存：
   - **キーワード**: 例 `Shopify 制作会社`
   - **カテゴリ**: 収集結果のカテゴリ分類に使用
   - **地域**: 例 `東京`（キーワードに地域を付加）
   - **除外キーワード**: 例 `比較, ランキング`

### 5-3. ディレクトリ収集

業界団体の会員一覧や比較サイトの掲載企業リストから収集できます。

1. 「URL収集」→「ディレクトリ収集」タブ
2. 企業一覧ページのURLと最大ページ数を入力
3. **「収集開始」**

### 5-4. Google直接検索（APIキー不要）

1. 「URL収集」→「Google直接検索」タブ
2. 検索キーワード・地域・取得件数を入力
3. **「検索収集」**

> Google利用規約に注意。過度な利用はIPブロックの原因になります。

### 5-5. Shopifyパートナー収集

1. 「URL収集」→「Shopifyパートナー」タブ
2. 最大取得件数を選択
3. **「Shopifyパートナー収集」**

### 5-6. Googleマップ収集

地域に根ざした企業や住所・電話番号情報が必要な場合に有効です。

1. 「URL収集」→「Googleマップ」タブ
2. 検索キーワード・地域・件数を入力
3. **「マップ検索」**

> Google Places API Keyの設定が必要です。

### 5-7. 法人DB収集（gBizINFO）

経済産業省のgBizINFO APIを使い、約400万社の法人情報から企業を収集します。

1. 「URL収集」→「法人DB」タブ
2. 業種・都道府県などの条件を入力
3. **「法人DB収集」**

> システム管理者がgBizINFO APIキーを設定している場合に利用可能です。

### 5-8. URLを直接入力して取得

1. 「URL収集」画面下部の「単一URL取得」または「一括URL取得」
2. URLを入力（一括の場合は1行1URL）
3. **「取得」** → 自動で会社情報を抽出・登録

### 5-8. 自動収集スケジュール

1. 設定画面の「自動収集スケジュール」
2. 「自動収集を有効にする」をON
3. 実行時刻を設定して **「保存」**

## 6. 候補企業の管理・評価

### 6-1. 候補企業一覧の見方

サイドバーの **「候補企業一覧」** を開きます。

| 列 | 説明 |
|---|------|
| 会社名 | 会社名とドメイン。Shopify/Amazon/楽天フラグバッジも表示 |
| カテゴリ | 自動分類されたカテゴリ |
| スコア | 0〜100点のスコアとランク（A/B/C/D） |
| 所在地 | 都道府県・市区町村・電話番号 |
| 問い合わせ | 問い合わせページへのリンク |
| ステータス | 現在の営業ステータス |

### 6-2. 絞り込み

- **カテゴリ**: EC制作、Shopify支援など
- **ステータス**: 未確認、アプローチ前、面談化など
- **スコアランク**: A/B/C/D
- **問い合わせ**: あり/なし
- **フリーワード検索**: 会社名・ドメイン
- **タグ**: 付与されたタグ

### 6-3. ステータスの管理

| ステータス | 意味 |
|-----------|------|
| 未確認 | 収集直後。まだ内容を確認していない |
| 対象候補 | 確認してアプローチ対象と判断 |
| 除外 | アプローチ不要と判断（業種不一致等） |
| アプローチ前 | アプローチ準備完了 |
| フォーム送信済 | 問い合わせフォームからコンタクト済み |
| 返信あり | 先方から返信が来た |
| 面談化 | 面談の約束が取れた |
| 代理店化 | 代理店契約完了 |
| 失注 | 断られた・見込みなし |

### 6-4. 企業詳細ページ

企業名をクリックすると企業詳細ページ（`/companies/:id`）が開きます。

- 基本情報の閲覧・編集
  - コンタクト担当者名（`contact_name`）・役職（`contact_title`）も入力・保存可能
- ステータス変更履歴
- 活動ログの記録・確認
- タグ管理
- フォローアップ日時の設定
- **AIサマリータブ**（AI企業分析・メール生成）
- **メール送信タブ**（SMTPメール直接送信・送信履歴）

### 6-5. 一括操作

複数企業を選択（チェックボックス）するとバルクアクションバーが表示されます：

**一括ステータス変更**:
1. 対象企業にチェック
2. ドロップダウンでステータス選択
3. **「一括変更」**

**プロジェクト間移動**:
1. 移動したい企業にチェック
2. **「プロジェクト移動」** → 移動先を選択 → **「移動実行」**

> 移動先に同じドメインが既に存在する場合は自動スキップされます。

### 6-6. 再スクレイピング

企業行の「回転矢印アイコン」をクリックすると最新情報に更新されます（手動調整スコアは保持）。

## 7. AI機能（企業分析・メール生成）

> **前提**: 設定画面でOpenAI APIキーを登録してください。またプランのAI分析回数上限内である必要があります。

### 7-1. AI企業分析

企業のWebサイトを自動スクレイピングし、AIが**事業内容・顧客層・強み・サービス・価格帯**を分析・要約します。

1. 候補企業一覧から企業名をクリックして企業詳細ページを開く
2. **「AIサマリー」** タブを選択
3. **「AI分析を実行」** をクリック（初回のみ数秒かかります）
4. 分析結果が表示される

> 分析結果はDBに保存されるため、2回目以降は即時表示されます。再分析は「再分析」ボタンから実行できます。

| 分析項目 | 内容 |
|---------|------|
| 事業内容 | 企業が何をしているかの要約 |
| 顧客層 | ターゲット顧客・業界・規模感 |
| 強み | 競合に対する差別化ポイント |
| サービス | 具体的なサービス・商品の一覧 |
| 価格帯 | 料金体系・価格感の情報 |

### 7-2. AIアウトリーチメール生成

AI分析結果をもとに、**件名・本文を自動生成**します。

1. 企業詳細ページの「AIサマリー」タブを開く（先にAI分析を実行）
2. 「アウトリーチメール生成」セクションでトーンを選択：
   - **フォーマル**: ビジネスライクで丁寧な文体
   - **カジュアル**: 親しみやすい話しかけるような文体
3. 「追加指示」欄に自由記述でカスタマイズ指示を入力（任意）
4. **「メールを生成」** → 件名・本文が自動生成される
5. 本文を直接編集して調整 → **「コピー」** でクリップボードに貼り付け

## 8. キーワード分析

どのキーワードが効率よく企業を収集できているかを可視化します。

### 8-1. 分析タブの開き方

1. サイドバーの **「検索条件管理」** を開く
2. 画面上部の **「分析」** タブをクリック

### 8-2. 分析指標の見方

| 指標 | 説明 | 目安 |
|------|------|------|
| 総獲得企業数 | そのキーワードで収集した企業の合計 | 多いほど収集効率が高い |
| 成功率 | 収集試行のうち企業が取得できた割合 | 50%以上が目安 |
| 重複率 | 収集した中で登録済みだった割合 | 高いと新規開拓効率が低下 |
| 拒否率 | 収集した中でまとめサイト等として除外された割合 | 低いほど精度が高い |

### 8-3. 効率バッジ

| バッジ | 条件 |
|--------|------|
| 高効率 | 成功率 >= 50% かつ 総獲得数 >= 10 |
| 中効率 | 成功率 >= 20% または 総獲得数 >= 5 |
| 低効率 | 上記以外 |

「低効率」のキーワードは検索語句の変更や除外キーワードの調整を検討してください。

## 9. マスターDB — 横断検索とインポート

マスターDBは**全プロジェクト共通の企業プール**です。どのプロジェクトで収集した企業も自動的にマスターDBに登録されます。

### 9-1. マスターDBの使い方

1. サイドバーの **「マスターDB」** を開く

**企業の検索**:
1. 検索バーにキーワードを入力（会社名・ドメイン・カテゴリ・都道府県）
2. カテゴリ・都道府県・最低スコアで絞り込みも可能
3. **「検索」** をクリック

**プロジェクトへのインポート**:
1. サイドバーで対象プロジェクトに切り替えておく
2. マスターDBで企業を検索
3. 「登録済み」バッジがない企業にチェックを入れる
4. **「現在のプロジェクトにインポート」** → 完了件数を確認

### 9-2. 活用シーン

- 「東京特化プロジェクト」の成果を「全国プロジェクト」でも使いたい
- 古いプロジェクトで収集した企業を新しいプロジェクトで活用
- 一度に多くの企業を素早く登録したい

## 10. ECサイトオーナー向けリスト収集（オプション機能）

> **オプション機能**: この機能はシステム管理者がテナントごとに有効化した場合のみ利用できます。サイドバーに「EC企業収集」メニューが表示されていない場合は、システム管理者にお問い合わせください。

ECサイトを運営している企業（ECサイトオーナー）を対象としたリスト収集機能です。Shopify・BASE・MakeShop・FutureShop・Stores などの主要ECプラットフォームを利用している企業を自動検出し、BtoB営業のターゲットリストを効率的に構築できます。

### 10-1. EC企業収集の開始

1. サイドバーの **「EC企業収集」** を開く
2. **業種・カテゴリを選択**（プリセットから選ぶか直接入力）
   - 例: ファッション・アパレル、食品・飲料、ホーム・インテリア など
3. **収集件数上限** を設定（デフォルト: 50件）
4. **「EC企業収集を開始」** をクリック
5. プログレスバーでリアルタイム進捗を確認
6. 収集完了後、検出されたECサイト企業が候補企業一覧に追加される

### 10-2. CMSプラットフォームの自動検出

収集した企業に対して、以下のECプラットフォームを自動判定しバッジを付与します。

| バッジ | 検出対象プラットフォーム |
|--------|------------------------|
| Shopify | Shopify（国内外） |
| BASE | BASE（国内EC） |
| MakeShop | MakeShop |
| FutureShop | FutureShop |
| Stores | Stores.jp |
| その他EC | 上記以外のECカート・決済ページを持つサイト |

### 10-3. ダッシュボードのEC統計

ダッシュボードの概要タブにEC関連の統計カードが表示されます。

| カード | 説明 |
|-------|------|
| EC企業数 | プロジェクト内でECサイトと判定された企業数 |
| CMSプラットフォーム別内訳 | Shopify / BASE / MakeShop / FutureShop / Stores / その他 の件数バッジ |

> CMSバッジをクリックすると、その企業一覧に絞り込まれます。

### 10-4. 企業一覧でのECフィルター

「候補企業一覧」でEC企業のみを表示するフィルターが利用できます。

1. 企業一覧の絞り込みバーを開く
2. **「ECサイトのみ」** トグルをONにする
3. 特定のCMSプラットフォームで絞り込む場合は **「CMSタイプ」** ドロップダウンで選択

### 10-5. CMS自動スキャン（バックグラウンド処理）

既存の収集企業に対してCMSプラットフォームを一括再判定する機能です。

- システムが毎日 **06:00** に自動実行します（管理者設定による）
- 手動で実行したい場合は管理画面の「スコアリングルール」→「CMS一括スキャン」から実行できます（システム管理者のみ）

### 10-6. マスターDBとの連携

EC企業はマスターDB（全プロジェクト共通プール）にも自動登録されます。

- マスターDB検索時に「ECサイトのみ」フィルターで絞り込み可能
- ECスコア（ec_score）が高い企業ほどEC事業の規模が大きいと判断されます

## 11. ダッシュボードの見方

### タブの切り替え（概要 / チーム）

## 18. 設定・通知

### Google Custom Search API

| 設定項目 | 説明 |

| Google API Key | Google Cloud ConsoleのAPIキー |
| Search Engine ID (cx) | Programmable Search Engineで作成したID |

取得方法:

2. Custom Search APIを有効化

| 設定項目 | 説明 |
|---------|------|
| OpenAI API Key | OpenAI PlatformのAPIキー（GPT-4o-mini使用） |

取得方法: [OpenAI Platform](https://platform.openai.com/api-keys) でAPIキーを作成

| 設定項目 | 説明 |
|---------|------|
| Slack Webhook URL | Slack App の Incoming Webhook URL |

取得方法:
1. [Slack API](https://api.slack.com/apps) でAppを作成
2. 「Incoming Webhooks」を有効化
3. 通知を送りたいチャンネルにWebhookを追加

### メール通知（SMTP）

| 設定項目 | 説明 |
|---------|------|
| SMTPホスト | メールサーバーのホスト名 |

| SMTPユーザー名 | 認証ユーザー名 |

メール送信タイミング: メンバー招待・パスワードリセット・フォローアップアラート（毎朝9時）

### フォローアップ通知

企業詳細ページでフォローアップ日時を設定した企業について、期限当日・期限超過を毎朝9時に通知します。

|---------|------|
| フォローアップ通知を有効にする | ON/OFFトグル |

### 自動収集スケジュール

| 設定項目 | 説明 |
|---------|------|
| 自動収集を有効にする | ON/OFFトグル |
| 実行時刻 | 毎日のバッチ実行時刻（サーバー時刻基準） |

### 2段階認証（2FA TOTP）

Google Authenticator などのアプリを使った二段階認証を設定できます。

**有効化手順:**
1. 設定画面の「2段階認証」セクションで **「2FAを有効にする」** をクリック
2. 表示されたQRコードをGoogle Authenticator（またはAuthy等）で読み取る
3. アプリに表示される6桁のコードを入力して **「確認」**
4. 次回ログイン時からメールアドレス・パスワードに加えてワンタイムコードの入力が必要になる

**無効化手順:**
1. 設定画面の「2段階認証」セクションで **「2FAを無効にする」** をクリック
2. 現在のワンタイムコードを入力して確認

> 2FAの有効化・無効化は既存の全ログインセッションを無効化します。

### Customer Portal（有料プランのみ）

Stripeカスタマーポータルへアクセスし、クレジットカード情報の変更・過去の請求書確認・サブスクリプション管理ができます。

1. 設定画面の「お支払い・プラン」セクションで **「カスタマーポータル」** ボタンをクリック
2. Stripeのポータルページにリダイレクトされます

### アカウントの危険操作（DangerZone）

設定画面下部の「危険ゾーン」セクションで以下の操作が行えます。**操作は取り消しできません。**

**全デバイスでログアウト:**
1. **「全デバイスでログアウト」** ボタンをクリックして確認
2. 現在ログイン中のすべてのデバイス・ブラウザのセッションが即時無効化される
3. 再度ログインが必要になる

**データエクスポート（GDPR対応）:**
1. **「データをエクスポート」** ボタンをクリック
2. アカウント情報・組織情報・設定・企業数などをJSON形式でダウンロード

**アカウント削除:**
1. **「アカウントを削除」** ボタンをクリック
2. 「DELETE」と入力して確認
3. Stripeサブスクリプションが即時解約され、全データが削除される

### 19-7. ECサイトオーナー向けリスト収集機能の管理（クライアントへの使用可否設定）

ECサイトオーナー向けリスト収集機能は**希望するクライアントのみに提供するオプション機能**です。テナント（組織）単位でON/OFFを切り替えられます。

#### 有効化・無効化の手順

1. サイドバー下部の **「管理画面」** リンクをクリック（`is_system_admin` 権限が必要）
2. **「テナント管理」**（`/admin/tenants`）を開く
3. 対象のテナント（組織）の行を見つける
4. **「EC収集機能」** 列のトグルスイッチをクリック
   - **ON（青）**: そのテナントのユーザーがEC企業収集機能を利用できる
   - **OFF（グレー）**: EC企業収集機能が非表示になり利用不可になる
5. 切り替え後、即時反映される（ページリロード不要）

> テナントが次回ログイン（または画面リロード）すると、サイドバーの「EC企業収集」メニューの表示/非表示が切り替わります。

#### 動作仕様まとめ

| 設定 | テナント側の表示 |
|------|----------------|
| EC収集機能 ON | サイドバーに「EC企業収集」メニューが表示される。ダッシュボードにEC統計・CMSバッジが表示される |
| EC収集機能 OFF | 「EC企業収集」メニューが非表示。EC統計も非表示 |
| システム管理者 | EC収集機能フラグの設定に関わらず、常に全機能にアクセス可 |

> **注意**: フィーチャーフラグ（`/admin/features`）の機能フラグとは別の設定です。EC収集機能はテナント管理画面のトグルで管理します。

## 20. よくある質問

### Q. 収集しても企業が0件のまま

A. 以下を確認してください：
- 設定画面でGoogle API KeyとSearch Engine ID (cx) が正しく保存されているか
- 「接続テスト」ボタンで接続が成功するか
- API使用量が上限（100回/日）に達していないか（ダッシュボードで確認）

### Q. 同じ企業が何度も収集される

A. 同一プロジェクト内では同一ドメインの重複収集は自動スキップされます。重複が発生している場合は「重複チェック」機能でマージしてください。

### Q. スコアが低い企業をフィルタで隠したい

A. 「候補企業一覧」のフィルターバーで「スコアランク」をA・Bに設定すると、高スコアの企業だけ表示できます。

### Q. 収集した企業を別のプロジェクトでも使いたい

A. 2つの方法があります：
1. **プロジェクト間移動**: 企業一覧でチェックして「プロジェクト移動」
2. **マスターDBからインポート**: マスターDB画面で検索して「インポート」

### Q. AI分析でエラーになる

A. 以下を確認してください：
- 設定画面にOpenAI APIキーが正しく保存されているか
- プランのAI分析回数（今月）が上限に達していないか（設定画面で確認）
- 分析対象企業のWebサイトURLが有効かどうか

### Q. プランの上限に達したとメッセージが出る

A. アップグレードモーダルが表示されます。管理者の場合は「プラン管理へ」ボタンからプランを変更できます。メンバーの場合は組織の管理者にご相談ください。

### Q. Googleマップ収集で「APIキーが設定されていません」と表示される

A. 設定画面の「Google Places API Key」フィールドに入力・保存してください（Google Custom Search APIとは別のキーです）。

### Q. 自動収集が実行されない

A. 以下を確認してください：
- 設定画面で「自動収集を有効にする」がONになっているか
- 「検索条件管理」でアクティブなキーワードが1件以上あるか
- 設定画面のスケジューラ状態が「稼働中」になっているか

### Q. Slack通知が届かない

A. 設定画面でWebhook URLが正しく保存されているか「テスト送信」で確認してください。また収集の成功件数が0件の場合は通知されません。

### Q. CSVに出力されるデータが少ない

A. 現在のフィルター条件のみが出力されます。全件出力する場合はフィルターをリセットしてからCSV出力してください。

### Q. 企業情報が不完全（会社名や電話番号がない）

A. Webサイトの構造によっては自動抽出できない場合があります。企業詳細ページから手動で補完してください。手動入力後はスコアが自動再計算されます。

### Q. 招待メールが届かない

A. 設定画面でSMTPメール設定が正しく保存されているか確認してください。設定が完了していない場合は、招待画面に表示される招待URLを直接コピーして共有する方法もあります。

### Q. SMTPメール直接送信で「送信失敗」と表示される

A. 以下を確認してください：
- 設定画面のSMTP設定（ホスト・ポート・ユーザー名・パスワード）が正しいか
- SMTPサービス側で「アプリパスワード」が必要な場合（Gmail等）は専用パスワードを使用しているか
- ポート587（STARTTLS）または465（SSL）のどちらかを使用しているか

### Q. チームタブにメンバーが表示されない

A. 組織にメンバー（自分以外）が1人以上いる場合に表示されます。「ユーザー管理」画面からメンバーを招待してください。

### Q. AIコスト管理の数値が表示されない

A. AI分析またはメール生成を一度も実行していない場合は「--」と表示されます。企業詳細ページでAI分析を実行するとログが蓄積されます（管理者ダッシュボードから確認可能）。

### Q. オンボーディングウィザードを再表示させたい

A. ウィザードは初回ログイン時に1度のみ表示されます。再表示はできませんが、設定画面から同じ項目をすべて設定できます。

### Q. gBizINFO（法人DB）タブが表示されない

A. フィーチャーフラグで無効になっているか、システム管理者がAPIキーを設定していない場合に非表示となります。システム管理者にご確認ください。

### Q. 「EC企業収集」メニューが表示されない

A. ECサイトオーナー向けリスト収集機能はオプション機能のため、デフォルトでは非表示です。利用希望の場合はシステム管理者（LeadHive運営側）にお問い合わせください。システム管理者がテナント管理画面からONにすると即時表示されます。

### Q. EC企業収集でプラットフォームが正しく検出されない

A. CMSプラットフォームの検出はWebサイトの構造に依存します。検出精度を上げるには：
- 管理画面の「スコアリングルール」から手動でCMS一括スキャンを実行してください
- システムは毎日06:00に自動再スキャンを実行しています

### Q. ダッシュボードにEC統計・CMSバッジが表示されない

A. EC企業収集機能が有効化されている場合のみ表示されます。サイドバーに「EC企業収集」メニューが表示されていれば機能は有効です。プロジェクト内にECサイトと判定された企業が0件の場合はバッジの数値が0と表示されます。
