**パイプライン ステータス一覧（左→右の順でカンバン表示）**

| ステータス | 説明 |
|-----------|------|
| 未確認 | 収集直後。まだ担当者が確認していない企業 |
| 対象候補 | 確認してアプローチ対象と判断した |
| 除外 | 営業対象外と判断（スクリーニングで除外） |
| アプローチ前 | アプローチ対象と確定したが未着手 |
| フォーム送信済 | 問い合わせフォームからコンタクト済み |
| 返信あり | 先方から返信が来た |
| 面談化 | 面談の約束が取れた（重要マイルストーン） |
| 代理店化 | 成約・代理店契約締結（完了） |
| 失注 | 商談不成立（完了） |
